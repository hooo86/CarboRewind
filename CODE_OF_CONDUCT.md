# Code de conduite / Code of Conduct

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Engagement / Pledge

Nous nous engageons à faire de la participation à ce projet une expérience exempte de harcèlement pour tous,
quels que soient l'âge, la taille, le handicap, l'origine ethnique, l'identité et l'expression de genre,
le niveau d'expérience, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Comportements attendus / Expected behavior

- Faire preuve d'empathie et de bienveillance ; respecter les opinions divergentes.
- Donner et recevoir des retours constructifs avec élégance.
- Assumer ses erreurs et en tirer des leçons.

## Comportements inacceptables / Unacceptable behavior

- Langage ou images à caractère sexuel, attaques personnelles, trolling, insultes.
- Harcèlement public ou privé ; publication d'informations privées d'autrui sans accord.

## Application / Enforcement

Les incidents peuvent être signalés de manière confidentielle aux mainteneurs via le signalement privé
du dépôt GitHub. Toutes les plaintes seront examinées rapidement et équitablement.
Les lignes directrices d'application complètes sont celles du Contributor Covenant 2.1.
